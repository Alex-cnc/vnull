## 三、纪律（写在清单里，免得两头都忘）

1. **每条完成都要有可复跑的验证**：单测 → 真机脚本 → 手工清单，三层按需，不含糊。
2. **状态只在验证之后改**：代码写完但没人点过的，标 `🟡（UI 已接，待人工验证）`，不标 ✅。
3. **文档漂移要当场纠正**：代码已实现而文档写「未实现」的（如 FR-DDL-03），先核再改，避免重复实现。
4. **每轮提交都推**：本地提交一律推送到远端。
