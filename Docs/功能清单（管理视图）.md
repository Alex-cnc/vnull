# 智能数据库客户端 · 功能清单（管理视图）

> 用途：给不熟悉技术细节的读者快速了解「现在能做什么、还差什么」。
> 编制日期：2026-09-22 ｜ 依据：《需求规范书》v3.26
>
> **一句话结论**：核心的日常使用功能已经可用；智能体（AI）等新功能的底层已经做好、
> 界面还没接完；国产数据库支持、数据导入等还没做。

---

## 一、现在就能用的（可直接演示）

| # | 能做什么 | 说明 |
|---|---|---|
| 1 | 连接数据库 | 支持 PostgreSQL；连接密码保存在系统钥匙串里，配置文件中不留密码 |
| 2 | 编写并执行查询 | 语法高亮、关键字补全、一次执行多段、执行中随时取消 |
| 3 | 查看查询结果 | 表格展示，可按列排序、筛选、翻页、复制 |
| 4 | 导出结果 | CSV / JSON / 表格文本 / Markdown（贴文档）/ 可直接回放的插入语句 |
| 5 | 浏览数据库内容 | 服务器 → 数据库 → 表 → 字段 逐层展开；可切换「按类型分组」查看表 / 视图 / 序列 / 函数 |
| 6 | 管理数据库本身 | 新建数据库、修改数据库属性（归属人 / 连接数上限 / 参数）、删除数据库（必须手动输入库名才能确认） |
| 7 | 权限管理 | 查看某个账号有哪些权限；授权 / 收回权限前先看到将要执行的语句 |
| 8 | 锁与阻塞排查 | 谁在等谁、等了多久、卡在哪个对象上，可一键定位到阻塞方 |
| 9 | 生成备份命令 | 生成整台服务器的备份命令供复制使用（只生成、不自动执行） |
| 10 | AI 助手：中文转查询语句 | 用中文描述需求，自动生成查询语句；结果只放进编辑框，**绝不会自动执行**；关掉总开关后完全不联网 |
| 11 | 大结果集导出 | 边读边写文件，不占内存；中途取消不会留下半截文件 |
| 12 | 高危语句保护 | 不带条件的批量删除 / 更新、删表、清空表等，执行前先弹窗列出风险再确认；可在工具栏关闭 |
| 13 | 只跑想跑的那段 | 可只执行光标所在的一条语句，或只执行选中的片段，不必每次跑整篇脚本 |
| 14 | 键盘快捷键 | 工具栏与菜单的每个按钮都有快捷键，点工具栏「?」可查看完整快捷键表 |
| 15 | 对象上直接操作 | 表 / 视图双击看数据；右键可浏览数据、生成查询 / 插入模板、复制表名、查看建表语句；删表 / 清空只生成语句、不自动执行 |
| 16 | 中英文界面切换 | 菜单里切换，立即生效 |

> 说明：以上「能用」= 代码完成 + 自动化测试通过（429 项）。**正式验收还需要用真实数据库逐项点一遍**，详见第五节。

## 三、还没做的（按重要性排序）

| 功能 | 影响 |
|---|---|
| **国产数据库 GBase 8a 的实际连接** | 只做了语句层面的适配，没有驱动程序，目前连不上。**已按要求下调为「优先级低的远景目标」**：需要真实实例与驱动才能开发验证，不阻塞本期交付 |
| SSH 跳板连接 | 连不上只能通过跳板机访问的数据库 |
| 表格里直接改数据 | 目前只能看，不能像 Excel 一样直接改单元格并保存 |
| 导入 CSV / Excel | 只能导出，不能导入 |
| 备份 / 恢复真正执行 | 目前只生成命令；真正执行要先定技术路线（见第四节） |
| 对象搜索（按名称找表 / 字段） | 库多了不好找 |
| 查看「建表语句」并复制 | — |
| 命令面板（快捷键唤起所有功能） | — |
| 多窗口 | 目前只有多标签页 |

## 四、需要拍板的事（不定就没法继续）

| # | 需要决定 | 为什么必须定 |
|---|---|---|
| 1 | **软件怎么分发**：上架应用商店，还是自己签名发给客户？ | 直接影响「备份 / 恢复」和「SSH 跳板连接」能不能真正执行——应用商店版本受系统沙箱限制，无法启动外部程序 |
| 2 | **要不要 Excel 导入导出** | 需要引入第三方组件，涉及安装包体积和许可证费用 |
| 3 | **要不要多窗口** | 涉及界面框架改动量 |
| 4 | **AI 用哪个模型服务**（本地部署 or 云端）以及密钥 | 没有它，AI 功能只能演示「界面」，无法真正出结果；本地部署可做到数据不出内网 |
| 5 | **GBase 8a 的版本号 + 测试环境** | 没有环境就无法开发驱动，也无法验证 |

## 五、正式交付前必须补的三件事

1. **用真实数据库逐项验收** —— 验收清单已写好（15 步，覆盖改库 / 删库 / 权限 / 锁排查），目前**一步都还没跑**。
2. **安装包签名与公证** —— 否则客户机器上会被系统拦截。
3. **一轮完整回归** —— 把上面第一、二节的功能在真实环境里全部点一遍并记录结果。
