| 项 | 当前值 | 说明 |

| `CFBundleShortVersionString` | `0.1.0` | 语义化版本：主.次.修订 |

## 3. 权限（Entitlements）

`App/PostgresClient.entitlements` 当前包含：

| 权限 | 用途 | 是否必需 |
|---|---|---|
| `com.apple.security.app-sandbox` | 沙箱 | ✅ |
| `com.apple.security.network.client` | 连接数据库 | ✅ |
| `com.apple.security.files.user-selected.read-write` | 打开 / 保存 `.sql`、导出结果文件 | ✅ |
| `com.apple.security.files.downloads.read-write` | 可选（若希望默认导出到下载目录） | ⬜ 未启用 |

原则：**不加多余权限**；密码只存钥匙串，不落地到容器文件。

## 4. 正式签名与公证流程

### 4.1 前置

| 项 | 要求 |
|---|---|
| Apple Developer Program | 有效账号（付费） |
| 证书 | `Developer ID Application: <团队名> (TEAMID)` |
| 密钥 | 私钥在钥匙串；建议用 App Store Connect API Key（`--key` / `--key-id` / `--issuer`）做公证 |
| 工具 | Xcode 命令行工具（`codesign` / `xcrun notarytool` / `xcrun stapler`） |

### 4.2 步骤

1. 构建 Release 产物：
   ```bash
   ./Scripts/build-app.sh release
   ```
2. 用 Developer ID 重签（替换 ad-hoc 签名）：
   ```bash
   codesign --force --deep --options runtime --timestamp \
     --entitlements App/PostgresClient.entitlements \
     --sign "Developer ID Application: <团队名> (TEAMID)" \
     dist/PostgresClient.app
   ```
3. 校验签名与权限：
   ```bash
   codesign --verify --deep --strict --verbose=2 dist/PostgresClient.app
   codesign -d --entitlements - dist/PostgresClient.app
   spctl --assess --type execute --verbose=4 dist/PostgresClient.app
   ```
4. 打包并提交公证（用 zip 提交最稳妥）：
   ```bash
   ditto -c -k --keepParent dist/PostgresClient.app dist/PostgresClient-0.1.0.zip
   xcrun notarytool submit dist/PostgresClient-0.1.0.zip \
     --key AuthKey_XXXX.p8 --key-id <KEYID> --issuer <ISSUER> --wait
   ```
5. 装订公证票据（stapler）：
   ```bash
   xcrun stapler staple dist/PostgresClient.app
   xcrun stapler validate dist/PostgresClient.app
   ```
6. 制作 DMG（可选）：
   ```bash
   hdiutil create -volname "PostgresClient 0.1.0" -srcfolder dist/PostgresClient.app \
     -ov -format UDZO dist/PostgresClient-0.1.0.dmg
   codesign --force --timestamp --sign "Developer ID Application: <团队名> (TEAMID)" dist/PostgresClient-0.1.0.dmg
   xcrun notarytool submit dist/PostgresClient-0.1.0.dmg --key … --key-id … --issuer … --wait
   xcrun stapler staple dist/PostgresClient-0.1.0.dmg
   ```

> 注意：换签名身份（ad-hoc → Developer ID）或换 Bundle ID 后，**钥匙串授权与沙箱容器会变化**：用户需要重新输入一次密码，已保存的连接配置会重新落在新的容器目录（当前版本的配置迁移需手工导出 / 重填）。

## 6. 架构与兼容性

| 项 | 方案 |
|---|---|
| 通用二进制 | `swift build --arch arm64 --arch x86_64`（或 Xcode `ARCHS=arm64 x86_64`）后再打包；当前只产出本机架构 |
| 最低系统 | macOS 14.0；如需更低版本需下调 `LSMinimumSystemVersion` 并回归 NFR-COMP-01 |
| 依赖内置 | PostgresNIO 及传递依赖已内置 / 固定版本（`Vendor/` + `Package.resolved`），发布包无需外部依赖 |
| 分发渠道 | 官网 / 内网直链（DMG）；如走 Mac App Store，需去掉 Developer ID 流程，改用 App Store 签名与审核（沙箱权限需最小化，`.sql` 文件通过用户选择持有安全书签） |

## 7. 回滚与支持

| 场景 | 处理 |
|---|---|
| 新版本出现阻断缺陷 | 停止分发新版本；提供上一版本安装包；必要时在 README / 发布说明中给出规避方式 |
| 配置不兼容（模型字段变更） | `ConnectionConfig.schemaVersion` 已预留版本号，可在加载时做迁移；当前为 1 |
| 用户报告连接失败 | 收集：服务器版本（`SELECT version();`）、`pg_hba.conf` 放行情况、SSL 模式、错误原文（App 内错误详情条）；对照 `Docs/兼容性矩阵.md` |
| 崩溃排查 | 收集 `~/Library/Logs/DiagnosticReports/PostgresClient-*.ips` 与操作步骤，登记到 `Docs/测试用例.md` §5 |
