## 一、现在能用

- **连数据库**：支持 PostgreSQL；密码存系统钥匙串，配置文件中不留密码
- **写查询、跑查询**：语法高亮、关键字补全、多段一次执行、执行中随时取消
- **看结果**：表格展示，可按列排序、筛选、翻页、复制
- **导出结果**：CSV / JSON / 表格文本 / Markdown / 可直接回放的插入语句
- **浏览库内对象**：服务器 → 数据库 → 表 → 字段 逐层展开；可按类型分组（表 / 视图 / 序列 / 函数）
- **管理数据库**：新建、修改属性（归属人 / 连接数 / 参数）、删除（必须手输库名才能确认）
- **权限管理**：查看某账号有哪些权限；授权 / 收回前先看到将执行的语句
- **锁与阻塞排查**：谁在等谁、等了多久、卡在哪个对象，可定位到阻塞方
- **备份命令生成**：生成整台服务器的备份命令（只生成，不自动执行）
- **AI 中文转查询**：用中文描述需求自动生成查询语句；结果只进编辑框，**绝不自动执行**；关掉总开关后完全不联网
- **高危语句保护**：不带条件的批量删除 / 更新、删表、清空表等，执行前先弹窗说明风险再确认（开关在工具栏「防护」里，可自行关闭）
- **大结果集导出**：边读边写文件，不占内存，中途取消不留半截文件
- 中英文界面即时切换
