## 维护约定

1. **文件名固定、版本在文档内维护**：不因版本升级改文件名，便于互相引用。
2. **需求只增不删**：需求编号不复用；废弃需求保留并标注替代编号。
3. **状态同步**：功能实现后更新 SRS 状态列，并登记验证方式（单测 / 脚本 / 手工 / 真机）。
4. **变更记录**：每次修改在文档末尾的「变更记录」追加一行。
5. **配套新增**：新增设计、测试、验证类文档时，先在本索引登记再创建文件。
6. **表格校验**：本目录文档的表格由脚本增量修改，改完必须运行
   `python3 Scripts/check-doc-tables.py`（校验列数一致、无 `||` 拼接行），避免表格错位。
