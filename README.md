# 智能数据库客户端

macOS 上的数据库客户端：连上数据库、写查询、看结果、导数据，并内置一个**默认关闭、开启后可看可审计**的 AI 助手。

- 工程名 `PostgresClient`，包标识 `com.vnull.PostgresClient`
- 当前支持的数据库：**PostgreSQL**
- 运行环境：macOS 14 及以上

## 能做什么

- **连数据库**：连接管理、按连接切换数据库；密码存放在系统钥匙串，配置文件中不留密码
- **写查询、跑查询**：语法高亮、关键字补全、一次执行多段、执行中随时取消
- **只跑想跑的那段**：可只执行光标所在的一条语句，或只执行选中的片段
- **看结果**：表格展示，可按列排序、筛选、翻页、复制
- **导出结果**：CSV / JSON / 表格文本 / Markdown / 可直接回放的插入语句
- **浏览库内对象**：服务器 → 数据库 → 表 → 字段 逐层展开；可按类型分组查看
- **管理数据库**：新建、修改属性、删除（需手动输入库名确认）
- **权限管理**：查看账号权限；授权与收回前先看到将执行的语句
- **锁与阻塞排查**：谁在等谁、等了多久，可定位到阻塞方
- **高危语句保护**：不带条件的批量删除 / 更新、删表等，执行前先确认（可关闭）
- **AI 助手（默认关闭）**：用中文描述需求生成查询语句，结果只进编辑框、**绝不自动执行**；
  关闭总开关后完全不联网
- **键盘快捷键**：工具栏与菜单的每个按钮都有快捷键，点工具栏「?」可查看完整表

## 构建与运行

需要 Xcode（含 macOS 14 SDK）。不依赖 Xcode GUI 也能构建：

```bash
# 编译并跑 Core 单元测试（不需要数据库）
./Scripts/verify-core.sh

# 编译并组装 .app（ad-hoc 签名，本机可直接运行）
./Scripts/build-app.sh
open dist/PostgresClient.app
```

## 目录结构（简版）

```
Core/       核心逻辑：连接、执行、方言、元数据、结果处理、AI 助手能力
App/        SwiftUI 界面
CLI/        命令行版本（真实连接与查询执行）
Tests/      单元测试
Scripts/    构建与验证脚本
Docs/       产品文档
Vendor/     第三方依赖（PostgresNIO）
```
