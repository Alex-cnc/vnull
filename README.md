# Doyah Studio

**中文** · [English](README.en.md)

macOS 上的**原生数据库工作台**（Swift / SwiftUI，无 JVM、无 Electron）：连库、写查询、看结果、导数据，
内嵌**真实 PTY 终端**与**多语言代码编辑器**，并把 **AI 智能体**作为一等能力内置。

它和别的客户端的差别**不在模型更强，而在"敢用"**：智能体默认关闭，写操作逐次审批，
所有外发请求进同一份可查看 / 可导出 / 可清空的日志；**没有模型端点时，全部既有功能完整可用**。

- 产品名 **Doyah Studio**，包标识 `studio.doyah.DoyahStudio`
- 当前支持的数据库：**PostgreSQL**（多数据库是产品方向：方言层与驱动层按可插拔设计，
  GBase 8a 为下一个目标 —— 其方言与 SQL 生成层已实现，但**没有实例可验证**，技术验证说明保存在开发者本地）
- 运行环境：macOS 14 及以上
- **界面中英双语**：简体中文 / English，**运行时切换、不用重启**（见下「国际化」一节）

## 能做什么

- **连数据库**：连接管理、按连接切换数据库；密码存放在系统钥匙串，配置文件中不留密码
- **写查询、跑查询**：语法高亮、关键字补全、一次执行多段、执行中随时取消
- **只跑想跑的那段**：可只执行光标所在的一条语句，或只执行选中的片段
- **看结果**：表格展示，可按列排序、筛选、翻页、复制
- **导出结果**：CSV / JSON / 表格文本 / Markdown / 可直接回放的插入语句
- **底部终端**：内嵌真实 PTY 的 shell（宽字符、ANSI 配色、鼠标上报、DECCKM、右键菜单），
  在里面跑 `vim` / `tmux` / `psql` 都正常
- **工作区**：把本机一个目录当工作区，文件树懒加载；点文本 / 代码文件直接在编辑器里打开，
  按文件类型做**关键字着色**与**补全**（JS / TS / SQL / HTML / CSS / JSON / Python…），⌘S 保存
- **浏览库内对象**：服务器 → 数据库 → 表 → 字段 逐层展开；可按类型分组查看；树里点文件即开
- **看结构**：ER 图（关系图 + Mermaid / DOT 导出）、Schema 对比与同步、表结构可视化编辑（列 / 索引 / 约束 + 实时 DDL 预览）
- **诊断**：执行计划、慢查询、数据库统计、锁与阻塞、会话与服务器级对象（角色 / 表空间 / 扩展）
- **数据进出**：导入 Excel（.xlsx）/ CSV（含 GB18030）/ TSV，可视化列映射与逐批日志；结果导出 Excel / CSV / JSON / Markdown / INSERT
- **内嵌浏览器**：编辑器区可开浏览器页签（默认不加载任何远程内容），下载走授权目录，出网全程留痕
- **管理数据库**：新建、修改属性、删除（需手动输入库名确认）
- **权限管理**：查看账号权限；授权与收回前先看到将执行的语句
- **锁与阻塞排查**：谁在等谁、等了多久，可定位到阻塞方
- **高危语句保护**：不带条件的批量删除 / 更新、删表等，执行前先确认（可关闭）
- **AI 智能体（默认关闭）**：自然语言 → SQL、规格 → 数据任务、任务调度与安全作用域导出；
  产物只进编辑框 / 待审批队列，**绝不自动执行**，执行前逐次审批，全程留审计
  （时间 / 连接 / 语句 / 模型 / 耗时 / 结果状态，可导出且不含密钥）；关闭总开关后完全不联网
- **界面语言**：简体中文 / English 一键切换（**就地切、不重启**，页签与正在编辑的内容都不丢），
  菜单栏、诊断文案、终端提示、工作区编辑器都跟着变
- **键盘快捷键**：工具栏与菜单的每个按钮都有快捷键，点工具栏「?」可查看完整表

更完整的清单（含"还没做的"）见 [功能清单（一页纸）](Docs/功能清单（一页纸）.md) 与
[功能清单（管理视图）](Docs/功能清单（管理视图）.md)。

## 现在到哪了（边界，如实写）

- **一等公民是 PostgreSQL**（16.2 与 18.6 均实测）。GBase 8a / MySQL 的方言层与 SQL 生成层已实现，
  但**没有实例可验证**，因此不列为"已支持"。
- **需求规模**：223 条（FR 168 · NFR 43 · AC 12），当前 FR 状态 **113 ✅ / 47 🟡 / 8 ⬜**
  （🟡 = 已实现但缺人工验收、或依赖外部环境；状态由 `Docs/需求规范书.md` §10.1 索引派生，
  `Scripts/check-doc-tables.py` 每次校验，不手工维护）。
- **智能体**：默认关闭；需要自备 OpenAI 兼容端点（优先本地端点、可免 Key）。没有端点时，
  除智能体外的功能全部可用。
- **平台**：macOS 14+（本仓库）。Linux 版是**同一个产品的另一实现**，契约层已定、实现待建。
- **已知未做**：SSH 隧道（FR-CONN-18）、GBase / MySQL 驱动、编辑器行号列、部分智能体条目（需模型端点）。
- **沙箱构建**：走 App Store 沙箱时子进程受限（`pg_dump` / `ssh` / `^C` 一类不可靠），
  完整功能用 `DOYAH_NO_SANDBOX=1 ./Scripts/build-app.sh` 的构建。

## 国际化（从一开始就是设计的一部分，不是后补的）

- **1348 条界面文案**放在**同一张表**里，两种语言（English / 简体中文）齐备；语言**运行时切换、不用重启**
  （界面就地重建，页签与内容不丢）。
- **新文案不可能漏翻译**：单测强制"每个键两种语言都有、都不为空、英文里不许残留汉字、
  中文不许留英文原文、两边的格式占位符必须一致"；`Scripts/verify-all.sh` 里另有一道**棘轮**
  （Core 展示文本本地化）挡住"新写的界面上文字绕过表直接写死"。
- 菜单栏、诊断文案、终端提示、工作区代码编辑器走同一张表；本仓库的 README 也是双语的
  （[中文](README.md) / [English](README.en.md)）。

## 构建与运行

需要 Xcode（含 macOS 14 SDK）。不依赖 Xcode GUI 也能构建：

```bash
# 编译并跑 Core 单元测试（不需要数据库）
./Scripts/verify-core.sh

# 编译并组装 .app（ad-hoc 签名，本机可直接运行）
./Scripts/build-app.sh
open dist/DoyahStudio.app
```

## 目录结构（简版）

```
Core/       核心逻辑：连接、执行、方言、元数据、结果处理、AI 智能体能力
App/        SwiftUI 界面
CLI/        命令行版本（真实连接与查询执行）
Tests/      单元测试
Scripts/    构建与验证脚本
Docs/       产品文档
Vendor/     第三方依赖（PostgresNIO，PostgreSQL 驱动）
```
